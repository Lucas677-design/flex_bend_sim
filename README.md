FlexBend 3D 是一款专为柔性印刷电路板（FPC）设计的 KiCad 开源插件。它能将传统的二维平面 PCB 布局，一键转换为带有真实物理弯折的三维实体模型（STL 格式），直接用于 SolidWorks、Bambu Studio 或 ANSYS / COMSOL 等有限元分析软件。

*******解决的痛点*******
传统的 EDA 软件（包括 KiCad）主要针对刚性板设计。当设计师需要评估柔性板在三维空间中的折叠、弯折状态时，往往需要手动在机械 CAD 软件中重新建模。FlexBend 3D 填补了电气设计与机械结构仿真之间的空白。

✨ 核心功能
多段连续折叠：支持在同一轴向上（X 或 Y）设置多个矩形弯折区，生成平滑过渡的 3D 曲面。

智能包络裁剪：自动识别框内走线的最宽范围（包含线宽），精准裁剪生成的柔性基材底板，绝不浪费空间。

正负角度自适应：支持输入 -180° 到 180° 的自定义角度，完美实现向上凸起（正角度）或向下凹陷（负角度）。

高精度网格生成：基于底层连续曲率积分算法，生成的圆弧曲面如丝绸般顺滑，无任何生硬的折角。

同源坐标映射：走线与基材底板共用同一套三维空间映射函数，确保走线死死贴合曲面，绝不飞线。

*******安装指南*******
环境要求
KiCad 7.0 / 8.0 / 9.0 / 10.0

Python 3.8+

手动安装 (Linux / macOS / Windows)
找到 KiCad 的插件目录：

Linux: ~/.local/share/kicad/<version>/scripting/plugins/

Windows: %APPDATA%/kicad/<version>/scripting/plugins/

macOS: ~/Library/Preferences/kicad/<version>/scripting/plugins/

将本仓库中的 flex_bend_sim.py 和 icon.png 复制到上述目录中。

重启 KiCad 的 PCB 编辑器。

在顶部菜单栏选择 Tools -> External Plugins -> Flex Bend 3D Sim Export 即可运行。

*******使用说明*******
准备走线：在 F.Cu 或 B.Cu 层正常绘制你需要的 PCB 走线。

划定弯折区：在 User.1、User.2 等用户自定义层（注意：不能是布线层），画一个矩形框。

竖向长矩形 -> 代表沿 X 轴发生折叠。

横向长矩形 -> 代表沿 Y 轴发生折叠。

运行插件：点击菜单运行插件。

输入角度：根据弹窗提示，为每一个矩形框输入你想要的弯折角度（例如 90 或 -90）。

获取模型：插件会在你的 PCB 项目文件同级目录下生成一个 flex_bend_mesh.stl 文件，直接拖入 3D 软件查看即可。

*******底层算法解析*******
本插件的核心算法经历了多次迭代，最终采用了 “一维曲率连续积分 (CurveTable) + 严格解耦分治” 策略：

将图形分为独立的 X 轴折叠组和 Y 轴折叠组。

采用微积分思想，以 0.1mm 为步长，沿折叠方向连续积分每一点的切线角与高度。

在生成网格时，实时叠加 X 与 Y 轴的位移与高度（Z_total = Zx + Zy），从而在交叉区实现绝对平滑的三维映射。

*******已知限制与开发计划*******
交叉折叠干涉：在真实的物理世界中，一片薄膜无法在同一个点同时向 X 和 Y 两个方向弯曲而不产生皱褶（数学上的不可展曲面）。目前插件针对同轴向的多段折叠效果最佳。未来计划引入“分割网格 (Slicing)”或“开槽 (Slit)”算法来支持复杂的十字交叉折叠。

暂不支持直接在插件内定义基材厚度和铜箔厚度（目前硬编码为 1.0mm 和 0.2mm）。
